# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

We take the security of **Language Agnostic Chatbot** seriously.

If you discover a security vulnerability, please **DO NOT** create a public GitHub issue. Instead, report it privately via:
- GitHub Private Vulnerability Reporting (Security Advisory tab on GitHub)
- Or email: `security@example.com` (replace with maintainer contact)

### What to Include
- Detailed description of the vulnerability.
- Steps to reproduce or proof-of-concept payload (e.g. prompt injection, privilege escalation).
- Potential impact and affected endpoints.

### Response Timeline
- **Initial Response**: Within 48 hours.
- **Triage & Fix**: Within 7 business days for high or critical severity vulnerabilities.
